## Product title

NexaPDF: PDF Toolkit

## Short description

Read, scan, merge, split, sign and protect PDFs on Android.

## Full description

Manage your documents from one simple Android workspace.

NexaPDF brings essential PDF tools together in a clean, dark interface, with Portuguese and English support. Most core PDF operations run locally on your device, and you choose where to save every result.

**READ AND MANAGE**
- Open PDF documents and move between pages.
- Keep a local list of recently opened files.
- Share documents through Android's share sheet.

**ORGANIZE PAGES**
- Combine two or more PDF files.
- Extract a selected page range into a new document.
- Rotate every page in a copy of a PDF.

**CONVERT AND REDUCE**
- Create a PDF from selected images.
- Make scanned pages searchable with on-device OCR.
- Create a smaller, image-based PDF copy using quality presets. This compression mode rasterizes pages; searchable text, links, forms, and vector content may not be preserved. The original file is kept.

**ANNOTATE AND PROTECT**
- Add a short text note to a selected page.
- Draw a signature with your finger and insert it into a copy.
- Protect a PDF copy with a password.
- Open password-protected PDFs by entering the password.

**SCAN DOCUMENTS**
- Capture paper documents, adjust the page crop, and export as PDF using the Google ML Kit Document Scanner.
- The scanner may require Google Play services and its components to be available.

**PRIVACY-FIRST WORKFLOW**
- Select files explicitly through Android's file picker.
- Local tools process documents on the device.
- Original files remain unchanged when NexaPDF creates an output copy.
- No sign-in is required in the current build.

NexaPDF is under active development. OCR currently supports upright pages, and some features may have device or document compatibility limits. Always review a processed PDF before sharing it.
